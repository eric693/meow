# 喚雨機器喵 — Discord 陪玩接單管理機器人 + 網頁後台

單一 Node 程序同時執行 **Discord 機器人**與**管理後台網站**。
技術棧沿用 white2：Express + better-sqlite3 + 原生 JS SPA + cookie-JWT 帳密登入。

- 後台網址：<https://meow.crownai.ink>（nginx → `127.0.0.1:4100`）
- systemd 服務：`meow.service`
- 機器人：喚雨機器喵（`1535904466849501264`）

```bash
systemctl restart meow          # 重啟
journalctl -u meow -f           # 看即時日誌
npm run seed                    # 重設 .env 裡的管理員密碼
npm run register                # 手動重新註冊 slash 指令
```

## 跨伺服器串接（集團）

「陪玩群」與「員工群」可在後台 **系統設定 → 集團綁定** 綁在同一個集團。綁定後：

| 共用（集團層） | 各群獨立（伺服器層） |
|---|---|
| 訂單、核銷、退單 | 身分組設定（管理員／客服／陪玩／老闆／雨滴）|
| 雨幣錢包與流水 | 頻道與分類（下單分類、考場分類、訂單通知、意見箱）|
| 陪玩薪資、提領 | 機器人狀態文字 |
| 財務報表、CSV 匯出 | 投票（投票發在哪個群就屬於哪個群）|
| 客服接單業績 | |
| 人事名單、親密度、禮物、背包、VIP | |

實作方式：所有營運資料表的 `guild_id` 欄位存的是 **org_id**；`guild_org` 表負責
`guild_id → org_id` 對照，未綁定時 org_id 就等於自己的 guild_id（獨立運作）。
綁定時會把該群原有的營運資料整批搬進新集團（`migrateOrgData`），舊帳不會失聯。

## 交易流水帳（對齊公司既有匯出格式）

所有金錢往來——一般訂單 🧾、贈送禮物 🎁、身分組結帳 💳、系統調整 ⚙️——都寫進同一張
`orders` 流水帳，欄位與公司原本的匯出檔一致：

> 訂單編號｜交易時間｜交易類型｜經辦客服｜金主名稱｜陪玩名稱｜訂單原價｜實收金額｜陪玩抽成｜伺服器淨利｜狀態｜備註

後台「交易流水帳」頁支援：

- **新增／編輯／刪除／核銷／退單／批次核銷**（改金額會同步修正金主錢包與陪玩薪資）
- **篩選器**：月份、日期區間、交易類型、狀態、經辦客服、金主、陪玩、金額上下限、關鍵字，欄位可點擊排序
- **匯出 CSV / Excel / PDF**（套用當下篩選、不受分頁限制；Excel 有凍結窗格與自動篩選，PDF 為橫式表格附中文字型）
- **匯入歷史 CSV**：直接吃公司舊的流水帳檔，名稱自動建檔、重複訂單編號自動略過、
  可先「試算不寫入」確認筆數；匯入歷史資料不會變動目前的雨幣餘額

「報表與匯出」頁另提供四份報表各三種格式：財務流水帳、金主消費總表（排名／歷史／本月／VIP）、
陪玩業績結算表、陪玩提領薪資明細。

## 下單流程與指定段位

下單選單：**服務類型 →〔子類型〕→ 技術／娛樂 → 性別 →〔指定段位〕→ 加購 → 需求單 → 專屬包廂 → 發布**。

| 服務 | 分類 | 指定段位 |
| --- | --- | --- |
| 雨幣儲值 | 不問 | 無 |
| 特戰英豪 | 技術／娛樂 | 技術單才問：頂尖賦能／賦能／神話3／神話／超凡／**不限段位**（限女生沒有頂尖賦能與神話3） |
| 英雄聯盟 | 技術／娛樂 | 技術單才問：菁英／宗師／大師／**不限段位**（男女同一份） |
| Steam 小遊戲 | 不問，直接問性別 | 無 |
| 唱歌單曲 | 不問，直接問性別 | 無（也沒有加購） |
| 語聊（一般／戀愛） | 不問，直接問性別 | 無 |
| 其他遊戲 | 技術／娛樂 | 無（需求單改問遊戲名稱與遊玩內容） |

- **不限段位**＝不篩選陪玩定級，該遊戲該性別的技術陪玩全部收到單。
- 指定某個定級時，**該定級以上**的陪玩也看得到（定級階梯 `order_rank_ladder`，
  預設 `超凡,神話,神話3,賦能,頂尖賦能`；英雄聯盟依預設派單表為 `大師＜宗師＜菁英`）。
- 相關設定：`order_services`、`order_rank_services`、`order_want_ranks`（男／不限）、
  `order_want_ranks_female`（限女生）、`order_want_ranks_lol`（英雄聯盟），全部留空就用內建預設。

## 派單分流（哪些陪玩看得到這張單）

後台 **系統設定 → 陪玩身分組分流規則**（`order_role_routes`），一行一條：

```
條件|條件=身分組,身分組
```

- 條件會逐一比對這張單的標籤：單別、服務、分類（技術／娛樂）、性別、指定定級（含「不限段位」）、
  加購項目（例如「聲優」）；**全部命中**才算符合，符合的規則會取聯集。
- `*` ＝不限；`!條件` ＝排除（該標籤命中就不算符合）。
- 排除語法主要用來拆開兩組會互相包含的字：`賦能` 會連「頂尖賦能」一起命中，所以賦能那行要加 `!頂尖`。
- 身分組可填 ID 或名稱（名稱支援部分比對）。

範例：

```
唱歌=喚雨歌手
技術|特戰英豪|限女生|神話=VAL女賦能,VAL女神話
技術|特戰英豪|限男生|賦能|!頂尖=VAL男頂尖賦能,VAL男賦能
技術|英雄聯盟|限男生|不限段位=LOL男菁英,LOL男宗師,LOL男大師
娛樂|英雄聯盟|限女生=LOL娛樂女陪
聲優=聲優男陪,聲優女陪
```

**留空時套用內建預設派單表**（`DEFAULT_ROLE_ROUTES`，在 `src/bot/panels.js`），涵蓋：

| 單別 | 依序 |
| --- | --- |
| 唱歌單 | 喚雨歌手（不分男女） |
| 特戰技術・女 | 賦能→VAL女賦能；神話→＋VAL女神話；超凡／不限段位→＋VAL女超凡 |
| 特戰技術・男 | 頂尖賦能→VAL男頂尖賦能；賦能→＋VAL男賦能；神話3→＋VAL男神話3；神話／超凡／不限段位→＋VAL男神話 |
| 特戰技術・不限男女 | 同段位的男女兩邊取聯集 |
| 特戰娛樂 | VAL娛樂男陪／VAL娛樂女陪，依性別 |
| LOL 技術・男女 | 菁英→LOL◯菁英；宗師→＋LOL◯宗師；大師／不限段位→＋LOL◯大師；不限男女取男女聯集 |
| LOL 娛樂 | LOL娛樂男陪／LOL娛樂女陪，依性別 |
| Steam 小遊戲、語聊 | 喚雨娛樂男陪／喚雨娛樂女陪，依性別 |
| 加購「聲優」 | 額外標 聲優男陪、聲優女陪 |

預設表在這個群完全對不到身分組時，才退回名稱自動配對（唱歌找含「歌手」、技術找含
「賦能／神話／超凡／VAL」再依性別與定級篩選、其餘找含「娛樂／聲優」），都沒命中則退回 `role_player`。

## PWA（安裝到手機／桌面）

後台與玩家手冊都是 PWA，用 Chrome／Edge／Safari 開 <https://meow.crownai.ink> 就能「加入主畫面」，
開起來是獨立視窗、沒有網址列，圖示為紫色雨滴。

- `public/manifest.webmanifest`：名稱、圖示（192／512／maskable）、主題色，
  以及三個捷徑（交易流水帳、薪資與提領、玩家手冊）——長按桌面圖示可直接跳頁。
- `public/sw.js`：**帳務資料一律不快取**。`/api/*` 永遠走網路，離線就直接失敗；
  只有 js／css／icons／manifest 走 stale-while-revalidate，頁面本身 network-first，
  離線時回退 `public/offline.html`。版本號 `VERSION` 改掉即清空舊快取。
- `public/js/pwa.js`：註冊 SW、`?p=<頁面>` 捷徑跳頁、離線提示條、
  偵測到新版時跳「更新」提示（按下去換版並自動重整）、可安裝時跳「安裝」提示（關掉後 30 天內不再問）。
- `sw.js` 由 `src/server.js` 以 `no-store` + `Service-Worker-Allowed: /` 提供，改版才推得出去。

iOS 需用 Safari →「分享 → 加入主畫面」（iOS 不支援安裝提示）。

## 核心金流

```
報單 → 老闆雨幣即時扣款 → 陪玩分潤進「暫存薪水 PendingIncome」
     → 客服 !核銷 → 轉入「可提領 Income」
     → 陪玩 !提領 / 後台建立提領 → 管理員撥款或退回
退單：退還老闆全額 + 扣回陪玩分潤（已核銷扣 Income，未核銷扣 Pending）
```

分潤成數（預設 80%，對齊既有資料）、VIP 門檻與 VIP 等級名稱皆可在後台「系統設定」調整。

**個別陪玩的分潤成數**：獨家／特約陪玩可單獨設定（`staff.share_rate`，`-1`＝跟隨全域），
後台「人事名單」可直接編輯，管理員在 Discord 也可用 `!分潤 @陪玩 85` / `!分潤 @陪玩 預設`（查詢：`!分潤 @陪玩`）。
報單與結帳一律以當下的個人成數計算，已成立的訂單不受影響，變更會寫進稽核紀錄。

## 專案結構

```
meow/
├── src/
│   ├── server.js      Express 入口（API + 靜態網站 + 啟動機器人）
│   ├── db.js          資料庫、集團解析 orgOf、雨幣、VIP
│   ├── auth.js        cookie-JWT 登入、模組權限、限流
│   ├── bot/
│   │   ├── index.js   機器人核心與事件分派
│   │   ├── commands.js  10 個 slash 指令定義
│   │   ├── slash.js   slash 指令實作
│   │   ├── prefix.js  ! 前綴指令（查詢／報表／日常操作）
│   │   ├── panels.js  !setup-* 面板與按鈕／表單互動
│   │   └── perm.js    管理員／客服／陪玩權限判定
│   ├── routes/        core（訂單金庫薪資老闆人事）／extras（禮物背包客服單投票）／admin（報表設定帳號）
│   └── util/          money 金流、gifts 禮物親密度、reports 報表 CSV、embed 訊息樣式
├── public/            後台 SPA（index.html + css/style.css + js/*）
│   ├── rules.html     公開玩家手冊　　offline.html  離線頁
│   ├── manifest.webmanifest / sw.js / icons/   PWA（可安裝、離線提示）
├── db/schema.sql      資料庫結構
└── scripts/           seed.js（建管理員）／register-commands.js
```
