🌱 新手上路

  1. 選身份：到「身份大廳」點🧳 旅人完成入住，才看得到下單區與金主專區。
  2. 儲值雨幣：到「點我下單」選雨幣儲值，系統會直接開一間儲值頻道給客服處理，不必填需求單。雨幣會直接進你的「地下金庫」。
  3. 挑陪玩：到陪玩名片區逛逛，每位陪玩都有專屬代號與影音名片，記下你喜歡的那位。
  4. 下單：到「點我下單」點「我已閱讀，開始下單」，依序選擇 服務類型 → 偏好性別 → 加購選項，最後填寫時段與備註。不同服務問的東西不一樣，選單會自動跳過用不到的步驟。
  5. 等名片：系統會開一間你的專屬包廂，發布後陪玩會進來遞交名片，你挑喜歡的那位。
  6. 結帳：服務結束由客服結帳，你會收到完整的結帳明細與訂單編號。
看不到某些頻道？九成是身分組沒領，回第 1 步點一下就好。

🪙 雨幣與地下金庫

雨幣是站內唯一的消費單位，所有下單、送禮都從雨幣餘額扣款。你的餘額存在「地下金庫」裡。

  • 查餘額：!消費查詢，或點「地下金庫」面板的查詢按鈕（只有你自己看得到）。金庫裡會顯示雨幣餘額、VIP 等級、歷史與本月消費、禮物累計，手上有券的話也會列出來。
  • 儲值：私訊客服，客服入帳後餘額立即更新。
  • 雨幣不足時無法下單，系統會直接告訴你還差多少。
  • 每一筆進出都有流水紀錄，帳目可查、不會消失。
雨幣僅供站內使用，恕不接受折現。請勿私下與陪玩交易，出事一律不受保障。

🧾 下單與核銷

一筆訂單會經過三個狀態

狀態意思
暫存中單子成立、你的雨幣已扣款，陪玩的錢先放在「暫存薪水」。
已核銷服務完成，客服核銷後陪玩的錢才轉成「可提領」。
已退單／撤銷訂單取消，雨幣全額退回你的金庫，陪玩抽成同步扣回。

下單要選的東西

全部都是點選單，選完最後才跳出一張需求單。不同服務會跳過用不到的步驟，不用擔心填到不相干的欄位。

服務類型會問你需求單欄位
雨幣儲值不問，直接開頻道無，跟客服說金額即可
特戰英豪技術／娛樂 → 性別 → 加購段位、希望時段、預計時長場次、備註
Steam 小遊戲性別 → 加購段位、希望時段、預計時長場次、備註
唱歌單曲只問性別希望時段、預計幾首歌曲、備註
語聊一般／戀愛 → 性別 → 加購希望時段、預計時長場次、備註
其他遊戲技術／娛樂 → 性別 → 加購遊戲名稱、希望遊玩內容、希望時段、預計時長、備註
  • 加購選項可複選：指定／甜蜜、聲優，每項加價 50 元一局；沒需求就選「無」。
  • 加購在發布訂單前就選好，包廂裡不會再問一次。
  • 特殊需求一律寫在備註欄，實際安排以客服確認為準。

包廂裡的三顆按鈕

需求單送出後，系統會開一間你的專屬包廂。確認內容沒問題，再決定要怎麼發布：

按鈕會發生什麼
✅ 確認訂單以匿名發布。另開一間名片專區給陪玩，不會顯示你是誰，名片會轉發進你的包廂。
📢 公開訂單把包廂直接開放給陪玩，看得到是誰下的單，陪玩在你的包廂裡遞交名片。
❌ 取消訂單取消這張單，頻道 5 秒後刪除。
徵滿了可以按「🗑️ 關閉名片專區」提早收單。結帳後包廂會自動改名為「已結帳」並歸檔。

付款方式

結帳時客服會讓你選 💸 現金 / 轉帳 或 🪙 雨幣餘額扣款。兩者1 比 1 等值，消費額、VIP 進度、親密度計算完全相同；差別只在現金／轉帳不會扣你的雨幣餘額。

退單請在服務開始前提出。服務已開始或已完成恕不退費；惡意退單將列入黑名單。

👑 VIP 等級

💞 送禮與愛戀藏館

送禮除了讓陪玩開心，還會累積你與對方的羈絆點數。消費 1 元 = 1 點羈絆，下單與送禮都算，送禮完成後會公開一則送禮明細。

羈絆階級

階級所需羈絆點數
萍水相逢0
點頭之交500
暖心夥伴2,000
心動訊號6,000
甜蜜戀人15,000
生死相許40,000
此生唯一100,000
  • 查羈絆：/愛戀查詢 [陪玩]，或點「愛戀藏館」面板。
  • 禮物款式從小貓粽到銀河共 15 種以上，價格與加成都寫在面板上。
  • 羈絆是「你 × 某位陪玩」一對一計算的，不會互相影響。
親密度若被管理員歸零，該組 CP 的歷史送禮紀錄會同步清除，無法復原。

🎒 背包與地盤

背包

活動獎勵、折價券都會放進你的專屬背包。用 /背包查詢 查看數量、面額與到期日， 點「地下金庫」的查詢按鈕也會一併列出你手上還沒過期的券。

地盤

地盤是一條 21 格的進度條，參加活動就能推進步數。走超過 21 格會自動歸 0 並完成一圈，完成整圈可向管理層領取該輪獎勵。

🎟️ 折價券與背包

客服會依活動或 VIP 進度發放折價券到你的背包，結帳時由客服在選單中套用，系統自動折抵。

券種說明
金額折抵固定折抵金額，例如「折價 100 元券」。
打折券依訂單金額打折，例如「85 折」。
  • 部分券有最低消費門檻（例如滿 1,000 才能用）與到期日，未達門檻或過期不會出現在選單裡。
  • 一筆訂單只能用一張券，可與客服的手動折扣疊加。
  • 查背包：/背包查詢，或點「會員服務中心」的查看背包優惠券。

🎤 想加入我們當陪玩？

  1. 到「點我入職」點「我要入職」，填寫考試項目、分級、性別。
  2. 系統會開一間 📝│考核單│你的帳號 專屬頻道，考官會在裡面與你聯繫、進行測試。
  3. 通過後由管理員用 /入職 建檔，綁定你的代號與影音名片，就可以開始接單了。
  4. 接單流程：在接單專區看到新訂單 → 點「遞交名片」 → 老闆的頻道會收到你的音卡。

陪玩薪資怎麼算

  • 接單成立 → 抽成先進「暫存薪水」。
  • 客服核銷 → 轉入「可提領」。
  • 用 !薪資查詢 隨時看「可提領餘額」與「暫存薪水（審核中）」兩筆數字。
  • !提領 金額 送出提領申請，管理員審核後撥款；管理員也可用 /提領 直接發放。
  • 服務完成後記得到報單頻道憑訂單編號報單並補上對局截圖，客服核銷後才會入帳。
  • 報單的老闆與陪玩欄位不限格式，填名字或 ID 都可以，客服會人工核對。
  • 報錯了不用緊張：核銷前都能重報覆蓋，或先用 !取消報單 訂單編號 清掉再報一次。訂單編號只有結帳時登記的那位陪玩本人能報。

📜 站規

  1. 尊重彼此：禁止辱罵、性騷擾、人身攻擊與任何形式的歧視。
  2. 禁止私下交易：所有金錢往來一律走站內雨幣，私下交易出問題概不受理，並列入黑名單。
  3. 禁止挖角與拉人：不得在站內招攬陪玩或客人到其他伺服器。
  4. 保護隱私：未經同意不得外流任何聊天內容、語音、照片或個人資料。
  5. 誠實下單：惡意退單、洗單、鑽漏洞刷取獎勵者，沒收餘額並永久停權。
  6. 有事說事：任何糾紛請走「意見投訴與建議箱」，管理層會保密處理。
違規處置由管理層依情節輕重決定，最重可永久停權且不退還餘額。本手冊內容如有調整，以站內最新公告為準。
